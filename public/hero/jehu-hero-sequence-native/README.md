# Native-source hero sequence

Generated from `jehu-galvez-transition.mp4` (1280×720, 24fps, 145 frames). Desktop preserves every source frame at native size, WebP quality 98. Mobile samples every other source frame at 960×540, WebP quality 94, retaining both endpoints. These are high-quality lossy WebP assets, not native 1080p or lossless video reproductions.

Regenerate with `python scripts/extract-hero-video.py --source path/to/jehu-galvez-transition.mp4`. Requires FFmpeg/FFprobe and Pillow only during generation. Source hash, frame indices, dimensions, phase boundaries, and transfer sizes are in `manifest.json`. The original supplied asset pack and old upscaled set remain unchanged.
